# T8: Autonomous Completion — Full Lifecycle Ticket

## Task
Create a Python utility `string_utils.py` with the following functions:

1. `reverse_string(s)` — reverse a string
2. `is_palindrome(s)` — check if string is a palindrome (case-insensitive, ignore spaces)
3. `word_count(s)` — count words in a string
4. `truncate(s, max_len, suffix="...")` — truncate string to max_len, adding suffix if truncated
5. `snake_to_camel(s)` — convert snake_case to camelCase

## Requirements
1. Write the implementation in `string_utils.py`
2. Write comprehensive tests in `test_string_utils.py`
3. All tests must pass
4. Initialize a git repo, commit everything with a descriptive message
5. Create a brief `DONE.md` documenting what was built

## Acceptance Criteria
- All 5 functions implemented and working
- Test file covers edge cases (empty string, single char, Unicode)
- All tests pass
- Git repo with clean commit history
- DONE.md exists with summary
